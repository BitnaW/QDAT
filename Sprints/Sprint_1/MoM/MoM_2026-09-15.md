## 2. Key Discussion Points

- **Problem and Background**
  - College of Arts & Sciences
  - Division of Government Services
  - Attended AI session hosted by Parteek.
  - Season does qualitative data.
  - NVIVO?
  - Tools do "auto-coding" but are really bad at it.
  - Transcripts of focus groups that are each 40-50 pages.
  - Search query sucks for transcripts.
  - Their syntax is bad.
  - Something related to what they are searching for.
  - Searching for one specific term, conversation, topic, etc.
  - People are loading their data into ChatGPT, Claude, etc., but data should not be loaded into an online AI system.

- **Proposed Solution**
  - Solution: Create an internal system that functions similarly for analyzing qualitative data.
  - Helps code and search data, find related concepts between data.
  - Takes around 4 weeks to do one job.
  - Don't want people putting data online.
  - Want to be able to code and query data faster and better without using external AI.
  - Not ethical or legal.
  - Has to beat NVIVO or Atlas.
  - Understand how it works and how to replicate internally.

- **Coding and Classification**
  - Deductive coding.
  - Know what you're coding for: Social, Capital, Cultural.
  - Classification.
  - Word frequency things (synonyms supposedly).
  - Coding definition: Numeric representation of a category.
  - Satisfaction, barriers.
  - Categorizing textual data into groups.
  - Codes are categories for buckets.
  - Social: connections within a community.
  - Networks, partners.
  - Built capital: Streets, electricity.
  - Codes might help people understand data at a glance.
  - What pops up the most.
  - Numeric values for qualitative responses.
  - Easier data summary.
  - Just really data analysis and finding trends and whatnot.
  - So I think it's just classification?

- **Features Wanted**
  - Better at searching, finding, required methods.
  - Use for: Searching, intent, general trends, outliers, themes (positive or negative).
  - Mapping: Tells documents that have certain codes in it.
  - Access to files, analyze and classify text in files.
  - Need to use something that has conceptual understanding of words.
  - What are the themes, where are they, how often do they show up in and across documents?
  - Just analyzing text, not audio or video.

- **Users**
  - Faculty.
  - Code things individually.
  - Make sure the coding is correct.

## 3. Decisions Made

- Create an internal system for analyzing qualitative data.
- Avoid using external AI systems because data should not be loaded online.
- The system should code and query data faster and better.
- The system should be better at searching and finding relevant information than existing tools such as NVIVO or Atlas.
- Focus on analyzing text, not audio or video.
- Support searching, coding, classification, identifying themes, and finding trends across documents.
