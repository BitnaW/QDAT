# Qualitative Data Analysis Tool

An AI-assisted tool for analyzing qualitative research data securely and efficiently.

## 1. Project Overview

The Qualitative Data Analysis Tool is a software project being developed for the Washington State University (WSU) Division of Governmental Studies and Services (DGSS).

Researchers often need to review large collections of survey responses, interview transcripts, and discussion notes to identify recurring ideas and themes. This process can be time-consuming when done manually, while existing AI tools may introduce data privacy concerns or make it difficult to verify where results originated.

Our goal is to develop a user-friendly application that helps researchers organize, search, and analyze qualitative data while maintaining control over their documents and analysis.

The application will use local language processing and clustering techniques to identify related ideas, suggest codes, and link analysis results back to their original source documents.

## 2. Project Goals

The main goals of this project are:

- **Secure data processing:** Keep sensitive research data local and avoid transmitting document contents to external services.
- **Automated coding:** Identify related passages and suggest codes or themes using machine learning techniques.
- **Document management:** Allow researchers to upload and organize multiple qualitative documents within a project.
- **Semantic search:** Find passages related to a search query based on meaning rather than exact keyword matches.
- **Source traceability:** Link codes and search results back to their original documents and text locations.
- **Code management:** Allow researchers to review, rename, merge, split, and organize codes.
- **Research summaries:** Help users understand recurring themes and patterns across multiple documents.
- **Usability:** Provide an intuitive interface for researchers without requiring specialized technical knowledge.

## 3. Planned Features

The following features are planned for the application:

- Upload and manage qualitative research documents.
- Process document text into smaller segments.
- Generate embeddings representing the meaning of text.
- Group similar text segments using clustering algorithms.
- Generate suggested codes from identified groups.
- View summaries of automatically generated codes.
- Search for semantically similar words, phrases, and passages.
- Navigate from analysis results to their original source locations.
- Adjust similarity and clustering parameters.
- Manually create, edit, merge, split, and reorganize codes.
- Store project data and analysis results reliably.
- Run analysis locally to support data privacy.

These features represent the intended project scope and may change as development progresses.
