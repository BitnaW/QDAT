# QDAT Frontend

This is the React frontend for QDAT. It currently includes a basic
front end layout.

## Running locally

From the repository root:

```powershell
cd code\frontend
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite, usually
<http://localhost:5173>.

To create a production build:

```powershell
cd code\frontend
npm.cmd run build
```
