# QDAT Frontend

This is the React frontend for QDAT. It currently includes a basic layout and
placeholder pages for the dashboard, documents, codebook, and search.

## Running locally

From the repository root:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite, usually
<http://localhost:5173>.

To create a production build:

```powershell
npm run build
```
